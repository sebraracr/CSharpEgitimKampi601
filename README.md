# 🚀 Müşteri Takip Sistemi (C# Windows Forms + MongoDB)

Bu repo, **C# Windows Forms** ve **MongoDB** kullanılarak geliştirilmiş bir **Müşteri Takip Sistemi** projesini içermektedir. Proje, müşteri bilgileri üzerinde CRUD (Create, Read, Update, Delete) işlemlerini gerçekleştirmeye olanak tanırken, müşteri kayıtlarını listeleme ve ID üzerinden arama özellikleri de sunmaktadır.

## ✨ Kullanılan Teknolojiler

- **C#:** Uygulama geliştirme dili
- **MongoDB:** NoSQL veritabanı yönetim sistemi
- **Windows Forms:** Masaüstü uygulama arayüzü
- **Visual Studio:** Geliştirme ortamı

---

## 📊 Proje Özellikleri

Bu projede yer alan temel özellikler:

- **Müşteri Listeleme:** Kayıtlı tüm müşterileri listeleme.
- **Müşteri Ekleme:** Sisteme yeni müşteri kaydı ekleme.
- **Müşteri Silme:** Mevcut müşteri kayıtlarını silme.
- **Müşteri Güncelleme:** Kayıtlı müşteri bilgilerini düzenleme.
- **ID'ye Göre Getirme:** Belirli bir müşteriyi ID bilgisi üzerinden bulma.

### 👤 Müşteri Kayıt Alanları

- ID
- İsim
- Soyisim
- Şehir
- Bakiye
- Alışveriş Tutarı

---
